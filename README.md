# ✨ Shourya Kumar — Portfolio

Hey there! 👋 Welcome to the repository for my personal developer portfolio.

I built this space to reflect how I approach software engineering: clean architecture on the back, fluid craft on the front, and plenty of playful, tactile details that make browsing the web actually enjoyable.

Live site: **[portfolio-shouryakumar.vercel.app](https://portfolio-shouryakumar.vercel.app)** *(or run locally below)*

---

## 🕹️ Highlights & Cool Interactions

- **Cinematic Minimal Preloader**: An interactive preloader screen with a glowing top progress bar and bottom-right live percentage counter (`0 %` → `100 %`) followed by a smooth curtain reveal on each page visit.
- **Custom Retro Arrow Cursor**: A bold, chunky black pointer with a crisp white border inspired by classic 3D artist toolkits. Built with hardware-accelerated `translate3d`, hover detection on interactive elements, and click-scale physics.
- **Interactive 3D Mechanical Skills Keypad**:
  - 20 custom 3D keycaps arranged in a 4×5 ortho matrix matching authentic mechanical keyboards.
  - **Zero-latency mechanical switch sounds** (always-on) synthesized directly in-browser using the **Web Audio API** (snappy clacks on hover, deeper bottom-out thocks on press, with organic acoustic pitch variation per switch).
  - Works with your actual physical keyboard — type keys on your keyboard and watch the corresponding switches light up and press down.
- **3D Particle Cloud & Donut**: Smooth interactive background rendered with Three.js that responds to mouse movement and scroll depth.
- **Fluid Micro-Animations**: Powered by Framer Motion with custom easing curves and responsive spring transitions.

## 💻 Getting Started Locally

Want to run this on your own machine? It only takes a couple of minutes:

```bash
# 1. Clone the repository
git clone https://github.com/shouryakumar246001/portfolio.git
cd portfolio

# 2. Install dependencies
npm install

# 3. Start the dev server
npm run dev
```

Then open your browser at `http://localhost:5173` (or the port Vite prints in your terminal).

To test the production build:
```bash
npm run build
npm run preview
```
